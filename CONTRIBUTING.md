# Contributing to Sigflo

Thank you for your interest in contributing to Sigflo.

Whether you're fixing bugs, improving documentation, testing features, reporting issues, or proposing new ideas, every contribution helps move the project forward.

## Our Mission

Sigflo exists to help people learn trading through practice, experimentation, and real-world experience.

When contributing, please keep this mission in mind.

We prioritize features that help users:

- Learn
- Experiment safely
- Understand markets
- Improve decision-making
- Develop trading skills

## Ways to Contribute

### Report Bugs

Found something broken?

Open an issue with:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots if applicable

### Suggest Features

Before proposing a feature, ask:

**Does this help users become better traders?**

Features that support learning, analysis, experimentation, and understanding are generally aligned with Sigflo's mission.

### Improve Documentation

Documentation is one of the most valuable contributions.

Good documentation lowers barriers for new users and contributors.

### Submit Code

Please:

- Keep pull requests focused
- Write clear commit messages
- Follow existing project conventions
- Explain the reasoning behind significant changes

## Community Principles

Be respectful.

Be constructive.

Assume good intent.

We are building tools for learning, not chasing hype.

## First-Time Contributors

If you're new to open source, look for issues labeled:

- `good first issue`
- `documentation`
- `help wanted`

Everyone starts somewhere.

Welcome aboard.
